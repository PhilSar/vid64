# ООО «ВиД» — производство дымоходов и вентиляции в Саратове

ООО «ВиД» изготавливает элементы для дымоходов и вентиляции, адресные таблички с подсветкой, столы и мебель из нержавеющей стали. В производстве используются лазерная резка, гибочное оборудование, аргоновая сварка, вальцовочные станки и другое оборудование.

Иллюстрации на главной странице — графические образы, а не фотографии выполненных заказов или реального оборудования. Фотогалерея изделий пока не добавлена.

## Запуск сайта

```sh
npm install
npm run dev
```

Сайт откроется по адресу, который выведет Vite (обычно `http://localhost:5173`). Проверки: `npm test`; production-сборка: `npm run build`.

## Заявки через Telegram

1. Создайте бота через [@BotFather](https://t.me/BotFather) и задайте `TELEGRAM_BOT_TOKEN` в корневом `.env`.
2. Укажите username бота без `@` в `VITE_TELEGRAM_BOT_USERNAME`.
3. Создайте окружение и установите зависимости: `python3 -m venv .venv && .venv/bin/python -m pip install -r bot/requirements.txt`.
4. Запустите `.venv/bin/python bot/bot.py` и отправьте боту команду `/id` из чата, куда должны поступать заявки.
5. Скопируйте ID из ответа в `TELEGRAM_ADMIN_CHAT_ID` и перезапустите бота. Перезапустите Vite, чтобы он подхватил username.

Форма сайта откроет Telegram с подготовленным текстом — клиенту нужно подтвердить отправку сообщения. Бот перешлёт его в указанный чат. Чтобы ответить клиенту, ответьте в Telegram непосредственно на скопированное сообщение клиента.
